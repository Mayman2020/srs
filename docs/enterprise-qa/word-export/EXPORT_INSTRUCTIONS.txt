STEPS FOR MICROSOFT WORD
  1. Open QA_Master_ForWord.html in Word (File → Open → select the file).
  2. Review page breaks (cover vs. body).
  3. File → Save As → Word Document (*.docx).
  4. Optional: Insert automatic Table of Contents (References → Table of Contents)
     so page numbers match your organization template.

REGENERATE HTML AFTER EDITING THE MARKDOWN
  In PowerShell:
    cd word-export
    .\Convert-MasterToWordHtml.ps1

PDF
  From Word: File → Save As → PDF, or File → Export → Create PDF.

FONTS
  Body uses Segoe UI and Traditional Arabic in CSS. In Word you may set
  default complex-script font to a corporate Arabic font if required.
